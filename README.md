# 文本差异显影台（TextDiffStage）

> **合同/公文双版本段落 LCS 对齐与隐蔽篡改显影台**  
> 一套 100% 本机离线运行的文本差异精确观测仪器。

---

## 它是什么

文本差异显影台专为解决合同比对、条款修订与公文回传中“被悄悄插入或删除隐蔽关键字”的问题设计：

- **段落 LCS 对齐**：基于 Bigram Jaccard 相似度动态规划配对段落，即使插入或删除整段，也不会导致全文上下错位；
- **字符级 Myers 内联高亮**：精准计算最小编辑距离，绿色下划线标示新增字符，红色删除线标示删减字符；
- **高危改动语义探针**：
  - **数字金额探针（NUMERIC_CHANGE）**：捕获百分比、阿拉伯数字及大写金额变动（如违约金 5% 变为 0.5%）；
  - **否定极性反转（NEGATION_FLIP）**：捕获“不/未/无/免除/禁止/无需”等否定词的增删；
  - **权利义务弱化（MODALITY_SHIFT）**：捕获“应当”改“可以”、“验收合格”改“基本合格”、“连带”改“按份”等责任推诿改动；
  - **纯标点空白过滤（FORMAT_ONLY）**：识别空格与标点微调，避免干扰实质条款审查。

---

## 它不是什么

- **它不是云端合同审核 SaaS**：100% 本机离线运行，不上传任何文档，绝不泄露商业机密；
- **它不是通用格式排版工具**：专注于文本内容与法律条款的语义差异显影；
- **它不是模糊生成式 AI**：所有比对与风险探针均基于严格透明的确定性算法。
